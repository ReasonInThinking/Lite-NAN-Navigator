### Простой Задачник LiteNan / Веб-версия: [Click](https://reasoninthinking.github.io/Lite-NAN-Navigator/)

LiteNan заточен под смартфоны. Предусмотрена голосовая диктовка задач в мобильной версии. Если нет интернета, а хочется выдавать задачи голосом, как вариант, установить [FUTO Keyboard](https://keyboard.futo.tech/). 

Приложение представляет собой место, куда записываются ежедневные задачи и глобальные цели. Глобальные цели выгружаются на устройство при необходимости (бэкап) и повторная загружаются в приложение. Помимо этого есть возможность заготовить дела на будущее, узнать сколько времени ушло на задачи, и удалить завершенный стэк, если того хочется. Вообще приложение делалось под свой когнитивный слепок, но возможно вам тоже оно понравится.  

Если вас заинтересовала моя болтовня и вы хотите увидеть мобильный задачник в своем устройстве, то принцип примерно таков: Скачиваете [apk файл](https://github.com/ReasonInThinking/Lite-NAN-Navigator/blob/main/LiteNAN.apk), открываете и устанавливаете. После установки - вероятно, приложение откроется с адресной строкой браузера. Поэтому оказавшись внутри устанновленного задачника переходите в настройки, находите такую или похожую словесную структуру и нажимаете по ней -> "установить и создать ярлык" ->  далее устанавливаете уже приложение где не будет верхней адресной строки. ДЛя лучшего удобства переносите приложение на основной экран, чтобы оно всегда было в шаговой доступности.
