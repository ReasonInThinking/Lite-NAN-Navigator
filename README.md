Простой Задачник LiteNan.

Веб-версия: [Click](https://reasoninthinking.github.io/Lite-NAN-Navigator/)

LiteNan заточен под смартфоны. Предусмотрена голосовая диктовка задач в мобильной версии. Если нет интернета, а хочется выдавать задачи голосом, как вариант, установить [FUTO Keyboard](https://keyboard.futo.tech/). 

Приложение представляет собой место, куда записываются ежедневные задачи и глобальные цели. Предусмотрено сохранение глобальных целей на устройство (бэкап) и повторная загрузка их в задачник. Еще есть возможность планирования дел на будущее, таймер, отслеживающий активную задачу и конечно "чистильщик" для удаления завершенных дел.

Если вас заинтересовала мобильная версия.. Скачиваете [apk файл](https://github.com/ReasonInThinking/Lite-NAN-Navigator/blob/main/LiteNAN.apk), открываете и устанавливаете его. После установки - вероятно, приложение откроется с адресной строкой браузер. Поэтому оказавшись внутри устанновленного задачника переходите в настройки, находите такое или похожее "установить и создать ярлык" ->  далее устанавливаете уже приложение где не будет верхней адресной строки. ДЛя лучшего удобства переносите приложение на основной экран, чтобы оно всегда было в шаговой доступности.
